\section{从设备造型开始：让模型成为可复用资产}
最初的目标很具体：使用 Three.js 与 Vite 制作四旋翼无人机和无人艇，并确保船首只有一个尖点。随后，模型数量从六款扩展至十二款。技术栈采用 TypeScript；截至本文的锁文件版本为 Three.js 0.180 系列、Vite 8 系列、TypeScript 5.9 系列，实际安装以 \texttt{package-lock.json} 为准。

六款无人机分别是轻型巡检、专业测绘、重载作业、近距巡检、应急照明与物资运输；六款无人艇分别是轻型巡检、水文测量、综合作业、水上救援、环境采样与长航时观测。每架无人机恰有四个旋翼组，每款无人艇采用单体船壳和唯一尖船首。

\subsection{把约束放进几何，而不是停留在描述中}
无人艇船壳由连续纵向截面构建，首端左右舷汇聚于中轴线上的同一顶点；底部、舷侧、甲板与船尾组成封闭表面。验证时检查闭合边、朝外绕序、体积符号及唯一船首，而非仅凭一个透视截图判断。

设备统一采用米制坐标、Y 轴向上、+Z 为前向。无人机原点位于中心机身，无人艇原点位于设计水线中心。模型模块不依赖页面、相机或工作台循环；返回的 \texttt{root}、\texttt{parts}、\texttt{update}、\texttt{dispose} 可供其他项目组合使用。

\begin{lstlisting}
const drone = createQuadrotor({ variant: 'inspection', scale: 1 });
const boat = createUSV({ variant: 'survey', scale: 1 });
scene.add(drone.root, boat.root);
drone.update(dt, { rotorSpeed: 12 }); // radians per second
// Independent lifetimes:
drone.dispose();
boat.dispose();
\end{lstlisting}

\subsection{交互承担检查工作}
模型工作台支持环绕、平移、缩放、标准视角、配色、线框、坐标轴、旋翼动画和截图。底视与俯视用于检查船壳、桨盘和设备布置。模型比例为演示设定，不构成制造图纸或产品规格。

\section{从基础水域走向具有空间尺度的工程环境}
最初的环境接口覆盖湖面、河道、港池、岛礁、桥区和滨水六类通用预设。随着视觉目标提高，主要展示入口转向深水港以及具体地点的桥梁、风电场、群岛。通用预设保留 API 兼容，但不再出现在当前环境列表中。

\shot{deepwater.jpg}{.68}{深水港原创工程示范：岸桥、堆场、船舶与远山提供米制尺度参照。}

\subsection{先说明实景依据，再说明可见内容}
深水港依据大型集装箱港口的工程组织逻辑建模，但其设施布局是原创示范，不能称为洋山港逐项测绘复刻。青州、九洲航道桥则结合公开地图与工程资料进行局部实景校核；没有资料支持的小构件仍需标明近似程度。

\shot{qingzhou.jpg}{.68}{青州航道桥：主跨、塔柱、桥墩与航道之间具有实际三维深度。}
\noindent\textbf{一个关键修正：}旋转观察深水港时曾出现岸壁闪烁。后续采用对数深度缓冲、检查重叠表面与近远裁剪范围，并保留环绕截图进行回归。宏大场景需要同时处理几何尺度与深度精度，不能仅把相机远裁剪面不断推远。

\section{天空为什么自然：统一光照，而非单独更换背景}
这套天空的基础是 Poly Haven 的 \textit{Kloppenheim 06 Pure Sky}，一个本地打包的 2K HDR 全景。它保留天空摄影的云层、亮度跨度与色彩渐变。背景按环绕方向采样，因此能够支持大范围旋转；云本身是静态摄影内容。

\subsection{同一环境影响天空、物体和水}
背景管理模块加载 HDR，将原图设为场景背景，并使用 PMREM 过滤结果作为物理材质的环境反射。程序从上半球最亮像素估算太阳方向，使方向光与水面高光共享方向。该估算服务于视觉一致性，并非天文时间和太阳方位测量。

当前天空强度为 0.75，环境强度为 0.65，曝光为 0.85，使用 ACES Filmic 色调映射。模型因此能够接收到天空的冷暖关系，而不只是在蓝色背景前独立打光。

\subsection{海天接缝与动态水面}
水面采用官方 Reflector 的平面反射通道，叠加自定义多尺度波纹法线、Fresnel 反射、太阳高光及运动触发尾流。远海依据 HDR 的地平线颜色雾化，减轻平面边缘与颜色断层。水位固定 Y=0，着色波纹不改变碰撞数据和船体姿态。

\shot{ninepin-waterline.jpg}{.74}{同一 HDR 光色贯穿云天、海面反射与岩岸材质，贴水镜头尤其能暴露接缝问题。}

\noindent\textbf{一次有效的隔离排查：}低机位出现三角形杂影时，先隐藏岸边泡沫，再隐藏岛体，杂影仍在；关闭噪声相位后杂影消失。最终将波纹的正弦散列替换为整数网格散列，修复了本机渲染中的噪声断层。没有将最初怀疑的“岛体封底”当作已证实原因。

\section{环境接口与多载具编辑：让画面能够复用}
环境模块位于 \texttt{src/environments/}，与设备模型和页面编辑器解耦。统一入口返回视觉根节点、空间数据、展示建议、更新方法和释放方法。下面是可在宿主项目中使用的最小组合；宿主仍需提供渲染器、相机与光照。
\begin{lstlisting}
const environment = createEnvironment({
  variant: 'ninepin', seed: 5104
});
const drone = createQuadrotor({ variant: 'inspection' });
const boat = createUSV({ variant: 'inspection' });
drone.root.position.set(-200, 10, 240);
boat.root.position.set(-200, 0, 240);
scene.add(environment.root, drone.root, boat.root);

function update(dt: number) {
  environment.update(dt);
  drone.update(dt, { rotorSpeed: 12 });
  boat.update(dt, { rotorSpeed: 4 });
}
\end{lstlisting}

\subsection{视觉定义与空间数据同源}
水域用 XZ 多边形及孔洞描述，岛屿从可通行水域中扣除。静态障碍采用平面轮廓加最低、最高高度；桥面与桥墩分别记录，使同一水平位置在不同高度得到不同检查结果。无人机使用完整桨盘扫掠包围范围，不随当前桨叶角度改变。

群岛障碍为整岛轮廓及最高点形成的保守柱体，低空贴坡可能产生保守重叠提示。此机制用于位置检查，不是精确网格碰撞或航行安全评估。

\subsection{配置只保存必要信息}
工作台支持重复添加十二款模型、平移与偏航编辑、数值输入、改色、删除、聚焦和显示层。无人艇 Y 固定为水位，无人机默认出生高度为 10 m。拖动控件期间暂停相机拖拽。

JSON 保存版本号、环境种子、载具 ID、型号、位置、朝向、配色与查看状态；导入时重新构造模型，不保存 Three.js 对象。结构损坏、未知型号及非法数值会在替换当前场景之前被拒绝。各环境保留页面会话草稿，长期保存依靠导出文件。

\subsection{释放与重复绘制}
重复风机、植被及设施使用实例化或共享几何。每个环境拥有自己的可释放资源，反射目标单独管理；多实例更新、暂停和释放互不影响。远景小于屏幕阈值的载具会被裁剪，标签承担全景中的定位任务。

\subsection{仍然保留的限制}
实时渲染截图不等于离线影视品质。项目尚未实现动力学、浮力、流体仿真、路径规划、实时天气或实测海床。桥梁小构件、风机附属设施与群岛岩柱仍有近似；深水港属于原创工程示范。验收日志和这些边界一起公开，才能使成果便于继续开发。

# 无人艇与四旋翼动力学

顶部「动力学」工作台把 18 款原始米制模型接到力与力矩驱动的积分器。模型页的「试验此载具的动力学」直接带入当前型号。外观展示页的缩放、配色和手动桨叶动画独立于物理实验，不会隐式改变质量或推力。

没有指定实艇、实机参数，因此本版本是**可校准的工程近似**，参数版本为 `engineering-estimate-v1`，不属于任何厂商的已辨识模型。模型方程经过数值性质和闭环行为验证；没有实测轨迹、拖曳试验、推力台架或飞行日志校验。

## 操作与记录

- 无人艇：加速、差速/单桨转向、断开动力滑行、航点跟踪、随流漂移。
- 无人机：起飞悬停、三维航点、侧风悬停；可在运行中修改目标位置和航向，关闭动力观察电机衰减和下落。
- 参数：质量、单桨最大推力、电机时间常数、阻力倍率。修改后复位；恢复按钮恢复当前型号的默认估算参数。
- 输入：风速、水流的世界 X/Z 分量、目标、动力开关及手动油门/转向可在运行中改变。UI 只给出当前实验用到的输入。
- 指标：地速、离地高度/艏向、倾斜角/艏摇角速度、每个电机的实际 rpm 和推力。箭头显示速度（长度按 2 倍放大）与推力方向；推力箭头长度不表示牛顿数。
- 回放：位置、四元数姿态、速度、各桨相位、推力和输入都取自选定历史帧。回放不会修改积分器；继续会回到最新状态。单步 0.02 s，记录间隔 0.1 s，最大时长 180 s。切换工作区暂停计算。
- JSON 包含完整物理配置、单位、积分步长、输入及状态序列。CSV 每行一个状态，四元数顺序 `x,y,z,w`、角速度 rad/s、转速 rpm、推力 N。未使用的推进器列留空。JSON 是实验记录格式，不是环境编辑器的场景配置。

## 坐标和积分

世界与模型都是右手系：X 右、Y 上、Z 前。无人艇 `u` 为艇体 +Z 纵向速度，`v` 为艇体 +X 横向速度，`r` 为绕 +Y 的角速度；正艏摇从 +Z 转向 +X。无人机角速度在机体系，平动速度在世界系。

所有公开 `step(dt)` 接受 `(0, 0.1]` 秒并检查有限值。艇体使用显式中点法，内部子步不超过 0.01 s。飞行器每步不超过 0.005 s，转动用中点角速度、四元数指数增量和归一化，平动采用加速度二阶位置更新。电机使用一阶响应的精确指数离散。动力学工作台的控制和物理子步均为 0.005 s，算法库以 0.01 s 子步执行。渲染帧率和 1/4/8/16/32 倍播放速度不改变物理步长。

非有限导数或越出积分保护范围会抛出异常，工作台保留上一个有效状态并停止，允许恢复默认参数。保护阈值为艇速 50 m/s、艏摇率 20 rad/s，飞机速度和角速度各 200 m/s、200 rad/s；这些是错误保护边界，不是载具能力声明。固定步长及默认控制增益只在本示例参数范围验证，极端质量/推力组合需要重新整定及更细步长。

## 无人艇：三自由度水动力学

采用 [Thor I. Fossen 的海洋航行器模型](https://fossen.biz/html/marineCraftModel.html) 的平面、重心居中、对角附加质量近似。保留刚体与附加质量的科氏/向心项、纵横向阻力及艏摇阻尼。

```text
M_RB ν̇ + C_RB(ν)ν + M_A ν̇_r + C_A(ν_r)ν_r + D(ν_r)ν_r = τ_prop + τ_wind
ν_r = ν − ν_current
D_i = d_linear,i + d_quadratic,i |ν_r,i|
ẋ = sin(ψ) u + cos(ψ) v
ż = cos(ψ) u − sin(ψ) v
ψ̇ = r
```

积分状态保存**绝对艇体速度**，恒定世界水流转换到随艇转动的坐标系，其导数项保留为 `(r v_c, −r u_c)`，因此水流不会通过直接平移位置来实现。空气力按风相对艇体的速度平方计算，默认空气密度 1.225 kg/m³，阻力系数并入估算迎风面积。

S-01 按单个可转向艉推进器建模：最大偏转 ±36°、最大偏转速度 45°/s；它不能原地回转。其他 9 款按模型中实际存在的左右推进器差速转向。推力正比于有符号轴速平方，倒车最大推力为正车的 65%，响应时间 0.25 s。左右轴独立响应并驱动对应模型桨叶；单桨总成跟随实际转角。

航向与速度控制只产生推进器指令，不直接设置艇体速度、位置或朝向。有限推力、反向能力及附加质量自然限制加速度、刹停距离和回转速度；几何路径上的尖角需要减速转向。

`I_z = m(L²+B²)/12`；附加质量为 `[0.08m, 0.65m, 0.35I_z]`。线性阻尼 `[0.12m, 0.9m, 0.35I_z]`，二次阻尼 `[0.045m, 1.5m, 1.2I_z]`，每项分别具有平动或转动对应的 SI 单位。这些比例只用于建立可运行初值，不是水池辨识结果。修改质量只同比调整刚体惯量；固定浸没几何下附加质量保持不变，水阻由独立倍率调整。附加质量的进一步辨识值可经核心 API 传入。

边界：固定设计水位，未解算静水吃水和重心变化；不包含波浪载荷、横摇、纵摇、升沉、船体形变、推进器通气/空化及船间水动力。环境库的水面纹理和尾迹是显示效果，不作为物理波浪输入。动力学试验场为无障碍静水面；算法库另有保守空间约束。

## 四旋翼：六自由度刚体

```text
m v̇_world = R(q) [0, ΣF_i, 0] − [0, mg, 0] + F_drag,world
I ω̇_body = τ_prop − ω × (Iω) − D_angular ω
F_i = k_F Ω_i²
τ_i = r_i × [0, F_i, 0] − spin_i k_Q Ω_i² [0, 1, 0]
Ω̇_i = (Ω_command,i − Ω_i) / τ_motor
```

四个旋翼顺序为前左、前右、后左、后右，转向符号 `[-1,+1,+1,-1]` 与几何模型一致。电机作用臂使用原始模型的 `armX/armZ`；反扭矩与旋翼方向相反。总推力始终沿机体 +Y，只有倾斜才产生水平推进。保留欧拉刚体的 `ω×Iω` 耦合项。空气阻力按机体系内的相对风速分轴计算。

控制结构参考 [PX4 的级联控制架构](https://docs.px4.io/main/en/flight_stack/controller_diagrams)：位置 P → 速度 PI → 四元数姿态 P → 角速度 P → 四电机分配。位置控制限制水平速度指令 6 m/s、爬升 3 m/s、下降 2 m/s；加速度转姿态的指令倾角上限 35°（实际瞬态可超调）。分配器在保持集体推力的同时缩小力矩请求，确保各电机处于有效范围；速度积分有幅值限幅及饱和/接地冻结。它是原创简化控制器，不是 PX4 固件或 SITL。

| --- | ---: | ---: | ---: |
| Q-01 巡检 | 2 | 2.2 | 0.055 |
| Q-02 测绘 | 4.8 | 2.2 | 0.055 |

| Q-04 近距 | 1.6 | 2.2 | 0.055 |

最大轴速按估算桨尖速度 110 m/s 除以桨半径得到；`k_F` 由最大推力反推。`k_Q/k_F = 0.045 × 桨半径`。惯量把 40% 质量视为分布在机臂端点，其余用机身高度项近似；完整惯量和阻尼数值可由导出 JSON 或 `profiles.ts` 读取。调高质量不会自动增加电机推力；推重比 ≤ 1 时会明确提示无法起飞。

边界：理想全状态反馈，没有传感器噪声、估计器、通信、导航误差、电池电压衰减、地效、桨间干扰、复杂气动或结构柔性。地面采用无反弹平面接地和摩擦/角速度衰减，按标称起落架高度处理，不是翻覆或碰撞损伤模型。

## 算法库如何接入

5 项算法默认 `motion: 'dynamics'`，`vehicle` 绑定所选型号，`current/wind` 使用世界 X/Z 分量。旧的一阶模型通过 `motion: 'kinematic'` 显式选择，便于独立比较规划和控制基线。

实际艇先做短时停车包络检查，通过推进器反向制动。每个物理子步再检查完整圆扫掠包络：若仍将碰撞，整个实验在最后安全状态**终止**并记录原因，不把位置冻结伪装为物理刹停。没有碰撞接触或局部重规划。瞬时风流变化和过小间距仍可能使轨迹不可执行。

动力学模式的一致性指令不再保证精确质心不变，任务完成同时检查低速和位置误差；覆盖按 0.8 m 采样半径统计。导出 JSON v2 保留模型参数及每帧的船体速度、艏摇率、推力、转角、轴速/相位；CSV 扩展相应列。三维旋翼直接使用采样相位，尾迹强度使用物理速度，因此回看和倍速不会虚构电机状态或放大尾迹速度。

## 复用和验证

核心入口：`src/dynamics/index.ts`。不依赖 DOM 或 WebGL；四旋翼仅使用 Three.js 的向量、矩阵和四元数数学类。`examples/dynamics.ts` 给出独立积分示例。`USVDynamics` / `QuadrotorDynamics` 的状态可读、`snapshot()` 深拷贝；调用者需要在外部管理环境和初值。不要按显示缩放盲目同比缩放质量、惯量和气/水动力系数。

`npm test` 校验自由运动能量、阻尼耗散、相对水流、有限推力及惯性、转向方向、重力自由落体、悬停平衡、倾斜推力、各型号闭环抗风、四元数规范化、电机响应、简化接地及时间步收敛。算法测试同时保留运动学性质和 5 项真实动力积分结果。

启动 `npm run dev` 后，`npm run test:dynamics` 检查 18 型号、运行/暂停/单步、动力开关、改变参数、航点与风、姿态同步、历史帧、JSON/CSV、相机、图层和 360/390 px 窄屏。`test:algorithms` 检查真实水域中的 5 项完整任务。`npm run build` 加生产预览验收检查发布产物。

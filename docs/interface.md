# 界面操作与按钮职责

四个工作区共用海蓝、墨色和浅灰的视觉系统，中央优先呈现三维内容，侧栏承载选择与参数。窄屏下模型和环境目录默认折叠；算法方法横向排列，参数面板可展开。动力学试验在窄屏优先显示三维视口和运行控制。控件有键盘焦点和中文名称；状态反馈不依赖颜色。

## 模型库

| 控件 | 实际作用 | 状态 |
| --- | --- | --- |
| 模型条目 | 切换到对应独立三维模型 | 当前型号高亮 |
| 查找模型 | 按名称、编号、任务、无人机/无人艇过滤 | 空结果提示；清空后恢复 |
| 透视、前视、侧视、俯视、底视 | 使用不同标准相机方向重新取景 | 手动拖动退出标准视角高亮 |
| 配色恢复 | 恢复当前型号的默认颜色 | 没有改色时禁用 |
| 保存图片 | 下载当前模型 PNG | 不含界面 |
| 全屏 / 退出全屏 | 展开 / 恢复当前模型视口 | 同一按钮切换文字 |
| 比例、颜色、线框、坐标轴、桨叶动画 | 更新当前模型及显示 | 动画关闭时禁用转速 |
| 试验此载具的动力学 | 以原始尺寸进入所选型号的运动试验 | 外观缩放不改变物理参数 |

透视视角已承担重新取景功能，不再额外放置同作用的复位按钮。目录长列表独立滚动，搜索保持可用。

## 环境库

| 控件 | 实际作用 | 状态 |
| --- | --- | --- |
| 环境条目 | 切换水域并保留会话草稿 | 当前环境高亮 |
| 添加型号 + 添加载具 | 创建实际模型实例并选择 | 最多 100 个实例 |
| 载具列表 / 标签 | 选择编辑对象；双击聚焦 | 对象、标签和编辑器同步 |
| 视角菜单 | 全景、俯视、鸟瞰、贴水或场景细节 | 只提供适用视角 |
| 聚焦所选 | 放大当前模型，便于编辑 | 未选择时禁用 |
| 平移 / 朝向 | 切换三维变换工具 | 无人艇固定水面高度 |
| 移除所选载具 | 删除当前实例 | 未选择时隐藏编辑组 |
| 六个图层和动画开关 | 标签、水域、障碍、出生点、水面与桨叶 | 无载具时禁用桨叶动画 |
| 保存图片 | 下载场景 PNG | 反映当前相机 |
| 专注视图 / 恢复编辑 | 扩展三维场景 / 恢复侧栏 | 同一按钮切换文字 |
| 导出 / 导入 JSON | 下载或恢复场景布局、配色和视角 | 导入校验并反馈错误 |
| 示例下载链接 | 下载初始 12 艇布局与静态航线数据 | 只在支持的三个集群场景显示 |

原来的两排取景控件合并为一个菜单；全景和复位不再重复。固定场景隐藏不会改变真实布局的种子按钮，基础程序化场景仍可重建。

## 算法库

| 控件 | 实际作用 | 状态 |
| --- | --- | --- |
| 13 个任务/方法条目及筛选 | 选择 8 项实际任务或 5 项规划/编队基线并生成默认方案 | 只展示该任务使用的参数，筛选后选中可见项 |
| 运动模型 | 水动力学 / 运动学基线 | 实际任务固定水动力学；原基线允许运动学对照 |
| 任务参数 | 前视距离、连续停留、巡逻圈数、观测/驻留时长和目标速度 | 仅显示适用字段；改动后重新生成 |
| 风流与动力参数 | 查看型号参数、设置世界 X/Z 风流分量 | 改动输入后重新生成方案 |
| 生成 / 运行 / 暂停 / 继续 / 重新运行 | 随实验进度完成主要操作 | 同一个主按钮；计算时禁用 |
| 单步 | 前进 0.1 秒 | 运行中或实验结束后禁用 |
| 回到起点 | 保留方案，清空运动进度 | 初始状态禁用 |
| 速度 | 控制仿真时间推进倍率 | 不改变物理速度参数 |
| 航线全景 / 艇群近景 / 任务俯视 | 查看路线、当前艇群或选点平面 | 无方案时禁用艇群近景 |
| 艇号标签 | 聚焦指定的三维艇模型 | 标签自动避让，引线标识位置 |
| 跟随 N 号艇 | 相机跟随选中的实际模型 | 手动操作退出跟随 |
| 场景选点 | 射线投影到水面，修改起点/终点/中心 | 岸线和障碍处拒绝选点；Escape 取消 |
| 轨迹回看 | 使用历史帧恢复位姿、桨相位、任务进度、检查点与参考目标 | 无历史或运行时禁用 |
| 实验 JSON / 轨迹 CSV | 下载参数、轨迹与结果 | 方案失效后禁用 |
| 编辑当前艇群 | 将当前/回看时刻带入环境编辑器 | 不替代算法页的实时三维播放 |

## 动力学试验场

| 控件 | 实际作用 | 状态 |
| --- | --- | --- |
| 载具 / 试验 | 切换物理配置及起飞、航点、手动推进或漂移初值 | 18 款型号，按载具显示有效选项 |
| 质量、单桨推力、响应、阻力 | 重建物理模型并复位 | 无效参数阻止运行和导出 |
| 恢复本型号参数 | 恢复该型号的估算初值并复位 | 已是默认参数时禁用，保留试验类型 |
| 动力接通 | 开/关电机指令 | 关闭后保留电机衰减和刚体惯性 |
| 目标、油门、转向、风流 | 修改后续物理输入 | 运行中可用；只显示当前实验使用的字段 |
| 运行 / 暂停 / 继续最新状态 | 推进或暂停积分 | 历史回看后继续最新时刻；参数无效或到时限时禁用 |
| 单步 0.02 s / 复位 | 推进一个控制步 / 返回初值 | 运行时禁用单步，初始时禁用复位 |
| 相机、向量、轨迹 | 跟随/全景/俯视，显示速度和推力方向或历史路径 | 对当前三维视口立即生效 |
| 历史回看 | 恢复对应时刻的完整姿态、桨叶相位及反馈 | 运行时禁用；读数也随历史变化 |
| JSON / CSV | 导出实际使用的物理参数及状态轨迹 | 包含尚未定时采样的当前时刻 |

## 验证

先运行 `npm run dev`，再执行：

```sh
npm test
npm run build
npm run test:browser
npm run test:algorithms
npm run test:missions
npm run test:dynamics
npm run test:ui
```

`test:ui` 覆盖按钮作用和启用条件、全屏、文件选择和下载、全部环境与视角、模型位姿同步、指定艇跟随、历史回看、三维射线选点、12 艇显示、无关隐藏参数隔离，以及桌面和 360 / 390 px 窄屏。结果记录在 `artifacts/ui/acceptance.json`，截图在同目录。

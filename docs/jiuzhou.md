# 九洲航道桥 · 实景校核版

新增入口 `jiuzhou`，保留深水港示范、青州航道桥。六个通用场景不回到展示列表。深水港仍标为“原创工程示范”，两处实景桥梁标为“实景校核版”，避免混淆来源。

## 来源与结构

跨径按设计单位作者论文的 85+127.5+268+127.5+85 米布置，693 米主桥、268 米主跨。采用 OSM 的实际九洲桥关系 14373675 与塔节点 6030181788 / 6030181789 确定中心和方位；Wikidata 当时误列青州桥的关系 14373679，未沿用该错误。

照片校核显示风帆框架位于纵桥方向，塔下存在开口，斜索位于道路中央区域。新场景单独构建弯曲帆肋、塔下开口、中央双索面和分叉墩，不使用青州桥的 H 形横塔和中国结结构。来源及精度清单见 `public/assets/jiuzhou/sources.json`。

已知：主跨与跨径组合、结构类型、地图位置、报道中的塔顶设计高程。待核实：工程高程与展示水位的转换、截面尺寸、精确曲线、索锚表、桥面宽高与灯具。当前未完成竣工精度复刻，不将通用天空或暂定海况称为现场采集数据。

## 接入

```ts
import { createEnvironment } from '../src/environments';
const site = createEnvironment({ variant: 'jiuzhou', seed: 5102 });
scene.add(site.root);
site.update(deltaSeconds);
// Leaving the scene:
site.dispose();
```

使用同一布局生成视觉对象与保守障碍。斜索按短段记录高度，主跨中央水面可通行。seed 保留统一配置接口，不随机改变真实桥型。完整渲染使用工作台相同的对数深度、HDR 与水面接口。

## 展示入口回归

展示注册表集中在 `src/scenes/environment-library.ts`。新增场景不再通过“只允许某一个 ID”的过滤写法替换列表；页面数量、摄像机和来源链接均由注册表派生。验收覆盖深水港的可见按钮、真实切换、各场景草稿恢复、独立来源链接，以及新场景释放和相机。

## 本轮验收（2026-10-21）

16 项测试、TypeScript 检查和生产构建通过。`npm run test:library` 实际点击深水港、青州桥、九洲桥，检查来源文件、独立草稿、四机位、俯视、暂停波纹、JSON 恢复及 390 px 窄屏。三轮切换后均为 108 个几何、7 个纹理资源，无浏览器错误。Intel Arc 140V / Edge、1600×885 画布、DPR 1、12 个载具静止全景约 60 FPS，P95 帧间隔 16.8 ms；不代表其他设备。截图与原始报告位于 `artifacts/library/`。

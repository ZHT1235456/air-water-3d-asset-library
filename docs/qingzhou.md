# 青州航道桥：实景校核版

用户已改为具体地点复刻，停止六类通用场景扩建。环境库列出青州航道桥、九洲航道桥和恢复入口的深水港示范，原有设备模型保持不变；六个通用环境构造代码保留用于旧配置兼容；深水港明确标记为原创工程示范。

## 数据与边界

运行资源中的 `public/assets/qingzhou/sources.json` 逐项记录证据、许可证及待校核项，页面提供可见链接。OSM 原始桥位轮廓随项目以 ODbL 提供；工程论文与参考照片不作为贴图发布。

桥跨按设计单位发表的 110+236+458+236+110 米确定，主塔位于桥轴的 ±229 米；中心和朝向由两个 OSM 主塔节点确定。场景 X 东、Z 南，Y 向上，桥轴按地图方位旋转。水面 Y=0 是展示基准，尚未与工程高程基准严格转换。塔柱总高 163 米由施工单位资料支撑；塔基标高、路面标高、截面、附属设施与索锚坐标未获竣工资料，均不属于经测量的精确数据。

仅构建 1150 米主桥及 1700×1200 米作业区域；外围海面仅为视觉延伸。未用虚构城市、岛山或简化引桥填充缺失范围。天空为已有 CC0 通用 HDRI，非现场采集。该版本是数据校核与交互基础，**尚未完成用户要求的完整实景复刻**。

## 可复用接口

`createEnvironment({ variant: 'qingzhou', seed: 5101 })` 返回统一环境句柄。`src/environments/qingzhou/config.ts` 管理已知尺寸和摄影机；`scene.ts` 从同一结构定义生成可见几何和高度障碍。桥面、主塔、承台独立记录，斜索拆成短棱柱，桥下水域仍可通行。保守碰撞范围不是工程净空认证。

## 稳定性修复

环境查看器启用对数深度缓冲，自定义水面同步写入对数深度；薄路面材质单独批处理并做深度偏移。深水港原码头正面墙与主体共面的位置已错开，避免近远尺度下旋转时争夺深度。环境模型本身不强制修改调用者的 renderer；外部接入时应创建 `new THREE.WebGLRenderer({ logarithmicDepthBuffer: true })`。

## 后续实景资料

精确复刻还需带坐标的竣工平立面/可授权 BIM、塔与索锚尺寸、同一高程基准以及现场多视角影像。当前可以核查主跨、桥位与结构类型，不能从公开概览图推断毫米级构造或实测精度。

## 2026-10-21 验证记录

类型检查、生产构建和 14 项测试通过。`npm run test:qingzhou` 验证唯一实景入口、对数深度开关、四机位、90 帧环绕、12 载具配置重建、三次加载资源稳定及窄屏。Edge 本机 1600×885、DPR 1、12 个载具静止视角测得约 60 FPS（不是其他设备的保证）。三次加载均为 1230 个几何资源、14 个纹理资源；无浏览器错误。原始结果和截图见 `artifacts/qingzhou/`。四个深水港角度截图用于复查共面问题；图像与自动断言不能证明所有设备上的频闪均已消除。
